# YiPex Mintlify Docs

This repository contains the Mintlify version of the YiPex operation guide migrated from GitBook.

Source: https://yipex.gitbook.io/yipex-docs

## Local preview

```bash
npx mintlify@latest dev
```

## Editing

After connecting this repository in Mintlify, edit pages from the Mintlify web editor or by editing the `.mdx` files in this repository.
